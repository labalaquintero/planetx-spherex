## Cómo repetir

1. Venv fuera del repo (Python 3.12/3.13): `py -3.13 -m venv C:\Users\<usuario>\.venvs\planetx-api` y `pip install -r api\requirements.txt` con ese Python (no modifica `requirements.txt`). Usar `PYTHONDONTWRITEBYTECODE=1`.
